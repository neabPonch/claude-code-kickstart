Claude Code Kickstart

It's an agent, not a chatbot.

Claude Code works in your repository — it reads your files, runs your commands, and verifies its own work. You point it at outcomes; you don't paste code into a chat box. This card is everything from the talk: install, the tour, and the habits that keep the bill honest.

Install — 4 steps, ~5 minutes

Steps 1–3 go in your terminal (Mac: Cmd+Space → “Terminal”; Windows: Start → “PowerShell”). Step 4 is typed inside Claude Code, in its chat-style input box. Sign in with your company Claude account when the browser opens.

terminal — 4 steps 
# 1 · install   (Windows PowerShell: irm https://claude.ai/install.ps1 | iex)
$ curl -fsSL https://claude.ai/install.sh | bash

# 2 · go to a real project you work on (any empty folder also works)
$ cd path/to/your/project

# 3 · start it — first run opens your browser to sign in
$ claude

# 4 · now INSIDE Claude Code: install the kickstart plugin, start the tour
> /plugin marketplace add neabPonch/claude-code-kickstart
> /plugin install kickstart@claude-code-kickstart
> /kickstart:tour

✅ Checks along the way: after step 1, a fresh terminal shows a version for claude --version; after step 4, typing /kickstart suggests the kickstart commands. Broken? claude doctor.

The five cost commandments

Your organization pays per token. These five habits are most of the difference between a cheap session and an expensive one.

1
Point, don't paste.
The agent reads files — stop shipping code through the chat box.
2
Plan before you build.
Redirecting a plan costs cents; redirecting code costs the code twice.
3
Give every request a “done when.”
Verified beats plausible.
4
Finished a task → /clear.
Five clean sessions beat one marathon.
5
Right-size the model and effort.
Save the big gun for problems worthy of it.

Session hygiene

The money commands.

CommandWhen
/clearTask finished, or two failed attempts at the same fix — start fresh.
/compactLong session mid-task; steer it: /compact keep the test failures.
/rewindLast approach was a dead end — roll code + conversation back.
/contextSession feels slow or off — look before you clear.
/usageSee what this session has spent.

Fit the tool to the task

Modes, models, memory.

Command / keyWhat it does
Shift+TabCycle permission modes — plan mode explores & proposes before touching anything.
/model · /effortBig model + high effort for gnarly work; cheap + low for mechanical.
/initGenerate the project's CLAUDE.md — then trim it; every line is a per-session tax.
/memoryEdit CLAUDE.md / memory files.
/resumeReopen an earlier conversation.

⚠ Auto-accept / auto mode: only for mechanical work on a clean branch with a verification target. While you're learning: manually approve, always.

The tour

Scripted, in your own project, one step at a time. ~8 lessons × ~5 minutes per part; a short intake adapts it to your role (engineer, analyst, operator). Stop anytime — progress saves to .kickstart-progress.md.

Part 1 · Foundations/kickstart:tour

Agent vs chatbot, CLAUDE.md, plan mode, context & cost hygiene, verification, checkpoints.

Part 2 · Daily driver/kickstart:tour2

Memory, permission policy, your first skill, branch/PR workflow, subagents, multi-session.

Part 3 · Power tier/kickstart:tour3

Hooks, custom agents, build a plugin, MCP, headless automation, CI, cost governance.

Anytime: /kickstart:coach audits your session for token waste · /kickstart:cheatsheet reprints this card in the terminal.
